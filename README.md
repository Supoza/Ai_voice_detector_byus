# ASVspoof 2019 Dataset Project

## 📌 Dataset Source
This project uses the **ASVspoof 2019** dataset from Kaggle:

🔗 https://www.kaggle.com/datasets/awsaf49/asvpoof-2019-dataset

## 📂 Project Structure
- **data/** – Place dataset files here after downloading from Kaggle
- **notebooks/** – Jupyter notebooks for analysis
- **src/** – Python scripts
- **results/** – Charts, logs, output files

## 🚀 How to Use
1. Download the dataset from the Kaggle link above.
2. Unzip and put the data into the `data/` folder.
3. Run the notebooks or scripts to begin analysis.

## 🛠 Tools and Libraries
- Python
- NumPy, Pandas
- Matplotlib / Seaborn
- Scikit-learn / PyTorch / TensorFlow (as needed)
